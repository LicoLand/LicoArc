# Code Of Conduct

## Our Commitment

The Lico Arc Protocol project is committed to a harassment-free, professional
environment for everyone, regardless of background or identity.

## Expected Behavior

- Be respectful, constructive, and technical in disagreement.
- Give and accept feedback gracefully.
- Focus on what is best for the protocol and its implementers.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing others' private information without permission.
- Bad-faith disruption of review, discussion, or the conformance process.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code
and may suspend repeat offenders from project spaces. Report unacceptable
behavior through the repository host's private reporting channels at
<https://github.com/LicoLand/LicoArc>.

## Scope

This code applies in all project spaces, including issues, pull requests,
reviews, and conformance discussions.

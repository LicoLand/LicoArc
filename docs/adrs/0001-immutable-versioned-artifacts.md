# ADR 0001: Versioned Candidate Artifacts And Publication-Time Immutability

Status: current definition-source decision.

## Context

Multiple independent implementations (clients and relays) must agree on the
federation contract without importing each other's source or this
repository's tooling. A mutable specification leaves "which contract did you
implement" unanswerable.

## Decision

- Schemas, field registries, and policies live by capability under `spec/v1/`;
  conformance corpora live under matching capability paths in
  `conformance/v1/`.
- `spec/v1/manifest.json` declares exact wire ID `licoarc.protocol-line.v1`, lifecycle
  `Candidate`, explicitly orders the canonical sources, and names the
  generated artifact.
- A generator bundles the canonical sources into a single candidate artifact
  (`artifacts/v1/licoarc.bundle.json`) whose SHA-256 `digest` binds the
  artifact version, wire ID, lifecycle, digest algorithm, manifest, and exact
  canonical serialization of every listed source.
- Candidate sources and generated bytes may change through reviewed source
  changes and deterministic regeneration.
- A formally Published Protocol Line is immutable; changes ship as a new
  version. Applying publication governance is downstream. See
  [../COMPATIBILITY.md](../COMPATIBILITY.md) and
  [../STATUS.md](../STATUS.md).
- Consumers that evaluate the candidate pin its exact artifact and verify its
  digest instead of importing this repository's source.

## Definition Source Evidence

- Source ordering and artifact destination:
  [`../../spec/v1/manifest.json`](../../spec/v1/manifest.json).
- Bundle generation and digest comparison:
  [`../../tools/generate-artifact.mjs`](../../tools/generate-artifact.mjs).
- Schema, field-registry, corpus, policy, scenario, and digest checks:
  [`../../tests/conformance.test.mjs`](../../tests/conformance.test.mjs).
- Human-readable source-integrity contract and commands:
  [../conformance/verification.md](../conformance/verification.md).

These links establish a deterministic Candidate definition.

## Consequences

- Integrity verification is a digest comparison, not a source audit.
- Every candidate source change requires regenerating the bundle; the
  `npm run artifacts:check` gate fails otherwise. See
  [../RUNBOOK.md](../RUNBOOK.md).
- The authoritative machine-readable definition remains the schema, field
  registry, and policy files, projected by
  [../protocols/foundation-v1.md](../protocols/foundation-v1.md).
